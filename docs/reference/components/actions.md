## `AppLink`

`next/link` for routes, a plain `<a>` for in-page `#` links. next/link scrolls to a fragment without moving focus, so a skip link through it would leave keyboard users where they were. `Button` and `Link` render through this; nothing else needs it.

Source: `src/platform/ui/AppLink.tsx`
