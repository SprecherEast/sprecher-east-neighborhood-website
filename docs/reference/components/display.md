## `Legend`

The legend under an annotated image or a chart (#636, from the diagram key of #515): one numbered circle per marker, drawn like the markers on the photo (a bold white number and a thick white ring on the diagram's own orange, `diagram-marker`, which doesn't change in dark mode), each with a bold label and a short line. It is a panel as wide as the image above it, with the image's caption (if any) between them: rounded all round, with a border (a shadow barely shows in dark mode) and a small shadow. It is still: no animation. Put it directly after the image block; it sits `--legend-gap` below it. The circles are decoration; screen readers hear "Marker 2: Westbound entrance loop" from a hidden prefix. Under a chart (#662), `marker="swatch"` draws each item's chart colour instead, with the hatch where the item has one, and `attach="none"` leaves out the panel. The swatch is a second cue beside the label, which is always text.

Source: `src/platform/ui/Legend.tsx`

| ----------- | ------------------------------------ | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `label`     | `string`                             | no       | What assistive technology calls the list, such as "Diagram key"; "Legend" by default                                                                                |
| `attach`    | `"none" \| "panel"`                  | no       | `panel` (the default) is a full-width box under the image block above it; `none` is a plain list, such as under a chart.                                            |

## `FeaturedImage`

The picture of a post or an event, at the top of the article's column (#1013): shown whole, at its own proportions, never cropped, so a picture that carries text (a panel of facts) stays readable at every width. It is the first image the visitor sees, so it loads early, and it takes the reading width from the column's left edge so its edges line up with the text. Its credit shows under it. With no picture it draws nothing, so no gap is left.
