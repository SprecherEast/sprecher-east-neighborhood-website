## `ImageMedia`

Renders an upload with next/image. `getMediaUrl` keeps upload paths relative (`/api/media/file/park.webp`), so Next optimizes them as local images (`images.localPatterns` in next.config.js). Uploads on an external CDN would need their host in `images.remotePatterns`.

## `MapEmbed`

A small map picture with its text, and a live Google map in a dialog when a neighbor taps either button (#764, docs/ui/component-set.md). The frame is created only once the dialog is open, so the page asks Google for nothing until then. A missing or unsafe address leaves the picture and the text, with no button.

Source: `src/platform/ui/MapEmbed.client.tsx`

## `Figure`

A picture that floats right in an article, small, with a short caption (#816). Clicking or tapping it opens the large picture with its numbered key and the long caption. The key is never in the small view: its numbers can't be read there. Without scripting the small picture stays as it is.

Source: `src/platform/ui/Figure.tsx`
