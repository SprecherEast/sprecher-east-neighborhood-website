# AI agent tools (MCP)

> Generated by `npm run docs:generate` from the MCP plugin options in the agents module and the loaded Payload config. Do not edit by hand: change the code, then run `npm run docs:generate`.

AI agents connect to `Sprecher East` at the MCP endpoint (see [endpoints.md](endpoints.md)). Each request carries an API key that acts as an agent account; the key is checked by `checkAgentKey` in `src/modules/agents/cms/mcp.ts`. For the tools the plugin makes, the content type’s access functions decide what a tool may do, and a key’s settings in Admin can only narrow that. The site’s own tools call Payload’s Local API themselves, which skips access unless a call says `overrideAccess: false`: each collection a tool reaches is marked “access checked”, “access bypassed” or “access depends on a value”, with the reason where the code gives one. “Reaches” is found by following the tool’s handler through the functions it calls in the source; a function passed in by the config is not followed, nor are the hooks a write sets off, which can write other collections (the search index, for example): each content type’s hooks are on its own page under Hooks. A collection passed to a shared helper is shown with what the helper does to it where its code shows that, otherwise as “operation not shown”. The calls counted are `find`, `findByID`, `findOne`, `count`, `findVersions`, `findVersionByID`, `findGlobal`, `findGlobalVersions`, `create`, `duplicate`, `update`, `updateOne`, `updateMany`, `updateGlobal`, `restoreVersion`, `delete`, `deleteOne`, `deleteMany`.

## Tools the site adds

Each field’s notes list every limit in the tool’s input schema, and the message of each custom check (`.refine`) written on the field, such as “each item once”, which the JSON schema cannot hold. A rule that compares fields (an event needs a start, say) belongs to the tool’s whole-input schema, which the handler checks, not to the fields registered with the plugin, and is not listed here: it is in the field’s description where the code gives one.

### `submitSuggestion`

Suggest an event or a news post, with its card summary and one or two category slugs from the categories find. It is stored as an unpublished draft for staff to review, never published, with the first category’s default image. Answers {"status":"created","id"} or, when the same externalId or contentHash is already stored, {"status":"duplicate","id"}.

Written in `src/modules/agents/cms/tools/submitSuggestion.ts`.

Reaches: [`agent-runs`](content-types/agent-runs.md) (read (access checked)), [`categories`](content-types/categories.md) (read (access checked)), [`events`](content-types/events.md) (create (access checked), read (access bypassed)), [`posts`](content-types/posts.md) (create (access checked), read (access bypassed)).

- `events`, read, from the comment on the function that makes the call: The item already stored with this source ID or fingerprint, if any. Read with access bypassed: suggestions are drafts the agent can't read, and only the id goes back to it.
- `posts`, read, from the comment on the function that makes the call: The item already stored with this source ID or fingerprint, if any. Read with access bypassed: suggestions are drafts the agent can't read, and only the id goes back to it.

### `reportItem`

Report something for an editor on your current run: needs-review, update, cancel or rejected-invalid, with a summary, evidence and the source link. It never changes the content it points at.

Written in `src/modules/agents/cms/tools/reportItem.ts`.

Reaches: [`agent-review-items`](content-types/agent-review-items.md) (create (access checked)), [`agent-runs`](content-types/agent-runs.md) (read (access checked)).

| Input              | Type            | Required | Notes                                                                                                                                                                                                                                                                                        |
| ------------------ | --------------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `runId`            | string          | yes      | The runId of your current run in agent-runs; 1 to 100 characters                                                                                                                                                                                                                             |
| `kind`             | string          | yes      | one of needs-review, update, cancel, rejected-invalid                                                                                                                                                                                                                                        |
| `targetCollection` | string or null  | no       | one of events, posts                                                                                                                                                                                                                                                                         |
