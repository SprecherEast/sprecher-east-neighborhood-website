# AI agent tools (MCP)

> Generated by `npm run docs:generate` from the MCP plugin options in the agents module and the loaded Payload config. Do not edit by hand: change the code, then run `npm run docs:generate`.

AI agents connect to `Sprecher East` at the MCP endpoint (see [endpoints.md](endpoints.md)). Each request carries an API key that acts as an agent account; the key is checked by `checkAgentKey` in `src/modules/agents/cms/mcp.ts`. The content type’s own access functions decide what a tool may do, and a key’s settings in Admin can only narrow that. “Reaches” is read from the tool’s own code: the collections it finds, creates, updates or deletes through Payload’s Local API.

## Tools the site adds

### `submitSuggestion`

Suggest an event or a news post, with its card summary and one or two category slugs from the categories find. It is stored as an unpublished draft for staff to review, never published, with the first category’s default image. Answers {"status":"created","id"} or, when the same externalId or contentHash is already stored, {"status":"duplicate","id"}.

Written in `src/modules/agents/cms/tools/submitSuggestion.ts`.

Reaches: [`agent-runs`](content-types/agent-runs.md) (read), [`categories`](content-types/categories.md) (read), [`events`](content-types/events.md) (create, read), [`posts`](content-types/posts.md) (create, read).

| Input          | Type            | Required | Notes                                                                                                   |
| -------------- | --------------- | -------- | ------------------------------------------------------------------------------------------------------- |
| `collection`   | string          | yes      | Where it goes: an event or a news post.; one of events, posts                                           |
| `title`        | string          | yes      |                                                                                                         |
| `bodyMarkdown` | string          | yes      | The full text, in Markdown. A <Chart … /> tag adds a chart; a malformed one is refused with the reason. |
| `summary`      | string          | yes      | The card text: one or two plain sentences, no Markdown or links.                                        |
| `categories`   | string[]        | yes      | One or two category slugs from the categories find, most specific first.                                |
| `startsAt`     | string or null  | no       | Events: required, a date-time with a zone.                                                              |
| `endsAt`       | string or null  | no       |                                                                                                         |
| `allDay`       | boolean or null | no       |                                                                                                         |

### `reportItem`

Report something for an editor on your current run: needs-review, update, cancel or rejected-invalid, with a summary, evidence and the source link. It never changes the content it points at.

Written in `src/modules/agents/cms/tools/reportItem.ts`.

Reaches: [`agent-review-items`](content-types/agent-review-items.md) (create), [`agent-runs`](content-types/agent-runs.md) (read).

| Input              | Type            | Required | Notes                                                 |
| ------------------ | --------------- | -------- | ----------------------------------------------------- |
| `runId`            | string          | yes      | The runId of your current run in agent-runs.          |
| `kind`             | string          | yes      | one of needs-review, update, cancel, rejected-invalid |
| `targetCollection` | string or null  | no       |                                                       |
| `targetId`         | integer or null | no       | With targetCollection: ids are per collection.        |
| `externalId`       | string or null  | no       |                                                       |
| `summary`          | string          | yes      | What an editor should know or do, in a few sentences. |
| `evidence`         | object[]        | yes      |                                                       |
| `flags`            | string[]        | yes      |                                                       |
| `sourceUrl`        | string or null  | yes      | Null only for rejected-invalid with no source link.   |
