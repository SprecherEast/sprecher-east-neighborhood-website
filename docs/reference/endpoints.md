# Endpoints

> Generated by `npm run docs:generate` from the loaded Payload config, the route files and the MCP setup. Do not edit by hand: change the code, then run `npm run docs:generate`.

Every way into the application that is not a site page: the route files, the REST and GraphQL APIs Payload builds from the content types, the custom endpoints, and the endpoint AI agents use. Site pages are in [routes.md](routes.md). Who may do what on each content type is on its page, under Access.

## Custom endpoints

| ------ | -------------------------------------- | ---------------------- | --------------- | ------------------------------------------------- | ------------------ |
| POST   | `/api/plugin-seo/generate-title`       | the config or a plugin | inline          | @payloadcms/plugin-seo                            | inside the handler |
| POST   | `/api/plugin-seo/generate-description` | the config or a plugin | inline          | @payloadcms/plugin-seo                            | inside the handler |
| POST   | `/api/plugin-seo/generate-url`         | the config or a plugin | inline          | @payloadcms/plugin-seo                            | inside the handler |
| POST   | `/api/plugin-seo/generate-image`       | the config or a plugin | inline          | @payloadcms/plugin-seo                            | inside the handler |

## MCP endpoint

AI agents connect at `/api/mcp`, with an API key that acts as an agent account. The key is checked by `checkAgentKey` in `src/modules/agents/cms/mcp.ts`. The tools, their input and the content types they reach are in [mcp-tools.md](mcp-tools.md). What runs on a timer is in [jobs.md](jobs.md).
